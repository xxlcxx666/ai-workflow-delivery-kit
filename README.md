## 一、这套工作流解决什么问题

设计团队接 AI 之后最常见的两种翻车：

1. **出图快了，交付没快**——初稿从三天变半天，返工却还是一天到两天，因为验收没升级；
2. **改稿四五轮**——方向没对齐就闷头做完整版，客户看完才发现不对，整版推翻。

根因相同：**判断发生得太晚**。本工作流只做一件事——把判断挪到执行之前。

实测口径（企业官网/品牌站，综合工时净值）：

| 指标 | 之前 | 之后 |
|---|---|---|
| 改稿往返 | 四到五轮 | 一到两轮 |
| 交付周期 | 十四个工作日 | 七个工作日 |
| 综合工时 | 基线 | 平均节省 40%（提案、改稿、归档全计入） |

边界：口径仅适用企业官网与品牌站；电商主图/详情页按批次作业，不适用此分母。等待客户反馈、节假日、需求反复的空转期均排除在外。

## 二、五阶段 SOP

```
① 需求确认 → ② 方向样张 → ③ 批量执行 → ④ 四道验收 → ⑤ 交付归档
   (判断前置)   (方向锁定)    (AI 接管机械)   (拦住细节错误)   (口径留档)
```

### ① 需求确认（不做这步，后面跑得再快也是空转）
- 动作：用《需求确认清单》把品牌定位、目标受众、内容范围在三页纸以内写清，**客户签字确认后才开工**。
- 产出物：三页确认单（模板见 `01-需求确认清单模板.md`）。
- 验收点：客户明确回复「按此执行」；有歧义项逐条问清，不带默认假设开工。

### ② 方向样张（把方向判断压进执行之前）
- 动作：首页视觉先出**两个方向**的版本，客户二选一锁定，然后才进入批量执行。
- 机制：AI 使方向试错成本降到可忽略——过去一个首页版本两天、改一天，现在一天三版，方向不对当场换。
- 验收点：客户在两个方向里做出明确选择；选择记录留档。

### ③ 批量执行（AI 接管机械部分，人保留判断）
- 动作：方向锁定后铺内页与延展；AI 批量产选项，**判断仍由人做**——机器提供选项速度，不替代判断。
- 验收点：内页与样张方向一致；任何偏离样张的产出打回重出，不进入验收。

### ④ 四道验收（30–40 分钟一套详情页；不做则返工通常 1–2 天）
- **规格**：比例、出血、安全区、CMYK/sRGB、300dpi——尺寸核对放在生成之前完成。
- **一致性**：字重、主色、光源方向、阴影角度同批统一；同批缩图并排铺开一眼扫，比逐张看更有效。
- **语义**：手的数目、文字成词、纹理连续、透视自洽；警惕训练数据残影（假角标、无意义文字）——放大到实际使用尺寸再看一遍。
- **授权**：参考图可商用、字体商用授权、AI 生成标识按目标平台规则逐家核。
- 清单见 `02-验收清单-四道检查.md`，可直接打印执行。

### ⑤ 交付归档（口径可核的来源）
- 动作：工时、轮次、返工成因按项目记入台账；复盘写进项目记录。
- 验收点：每个项目可回答三个问题——交付清单是否固定、周期与工时口径是否可核、复盘记录是否留下来。

## 三、提示词库（结构模板）

不写死某一款模型的咒语，给结构——换任何模型都能用：

**四段式结构：**
```
【主体】拍什么/画什么，一句话说清画面核心对象与动作
【环境】场景、光源方向、时段、氛围——与一致性检查对应
【规格】比例、用途（印刷/屏幕）、色域、禁忌（不要文字/不要水印）
【风格】参照系：材质、质感、构图视角、负面项（排除清单）
```

**三条纪律（对应验收四道）：**
1. 尺寸写进提示词生成之前定死——比例不对的图不要靠裁切救；
2. 同批物料共用同一套环境段——光源方向写死，杜绝「四张图四个太阳」；
3. 排除项写具体（no: 多余的手、伪文字、假商标角标）——比正面描述更管用。

## 四、给团队负责人的一段话

这套流程的复利不在单张图快多少，而在**检查清单一旦固定，新人也能按同一套标准执行，交付质量下限不再依赖某一个人的状态**。先定检查清单，再谈提效比例，顺序反过来要付两次学费。

## 五、口径声明

- 提效 40%：跨项目综合工时净值，含提案、改稿、归档，非单指画图环节。
- 14→7 工作日：企业官网/品牌站交付周期，工作日口径，非自然日；电商不适用。
- 所有数字来自本人项目台账，面试或合作洽谈时可逐条展开核验口径。
